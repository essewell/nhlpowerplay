# PowerPlay

NHL power-play coaching game. Start with `docs/KICKOFF.md`; Claude Code reads `CLAUDE.md`.

- `packages/engine` — likelihood model, modes (TypeScript, tested)
- `data-pipeline` — builds the real-data scenario and ratings database (Python, tested)
- `docs/DESIGN.md` — tokens and screens; `docs/design/` — design canvases (v2 is current) and exported assets
- `docs/COPY.md` — every user-facing string; `docs/KICKOFF.md` — build plan
- `docs/PROMPTS.md` — the Cowork and Claude Code prompts; `docs/DATA_RUNBOOK.md` — how the data is fetched;
  `docs/DATA_STATUS.md` — current data build status
